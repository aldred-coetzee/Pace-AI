# worklog

Generated by `box-config/bin/worklog` (nightly). Do not hand-edit.

- `worklog.md`: this repo's time, sessions, days and job runs, for people.
- `data.json`: the same as data. `prompts.jsonl` / `briefs.jsonl`: metadata only (time, session, ordinal, size, 4D tag `d`). No prompt text is stored in this repo; the text lives in the private box-config repo.
- Definitions and gaps: `box-config/worklog/README.md`.
